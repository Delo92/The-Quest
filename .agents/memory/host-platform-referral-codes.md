---
name: Host platform referral codes
description: Rules for host-wide referral links and their separation from competition share links
---

Every host profile should have one platform-wide referral code that resolves through the root-domain `?ref=CODE` format. It is separate from any competition-specific referral code.

**Why:** Hosts need a stable link they can share across all competitions, while competition links need their own attribution and destination behavior.

**How to apply:** Create the host-wide code automatically during host creation or promotion, preserve it when competition-specific codes are created, and show copyable links in host/admin dashboards.
