name: Quest admin navigation
description: Top-level destinations in the admin dashboard sidebar, including the placement of payroll tools.
---

Payroll & Agreements is a top-level destination in the System section of the admin dashboard, alongside Storage, Analytics, and Settings. It is not a nested Settings tab.

**Why:** Payroll is an operational workflow with its own payees, agreements, batches, and ledger, so hiding it inside platform configuration makes it harder to discover.

**How to apply:** Keep desktop and mobile navigation pointed at the outer payroll tab value, and reserve the Settings sub-tabs for Platform Settings and Diagnostics.
