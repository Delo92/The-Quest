---
name: Raplahoma invitation reminders
description: User-approved scope and completion rules for recurring Raplahoma artist invitation reminders
---

Only artist invitations for Raplahoma receive recurring reminders. The user chose an unlimited daily cadence that stops after the invitee accepts the invitation and has both a profile photo and a video. A pre-created account does not count as acceptance.

**Why:** Invitation creation can provision an account and talent profile before the recipient accepts through the invitation flow; profile readiness is a separate requirement.

**How to apply:** Keep reminders limited to Raplahoma talent invitations, check acceptance plus both media types before stopping, and preserve a manual pause/resume control for inviters. A successful mail submission is not proof of delivery.
