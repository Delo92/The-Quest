name: Category artwork references
description: Approved visual mapping and storage rule for The Quest category cards.
---

The approved category visuals are dedicated local artwork that visibly represents Music, Modeling/Fashion, Bodybuilding, Fitness, Dance, Comedy, Acting, Brand & Business, Sports, and Reality. Existing Firestore category records must be synchronized to those local web assets; Reality must never use the Starr Struck competition poster.

**Why:** Firebase Storage artwork URLs were broken in production, and reused competition covers or trophy artwork did not match several category descriptions.

**How to apply:** When changing category artwork, use a dedicated image whose subject matches the category description, keep it in the web bundle, update existing records as well as new seeds, preserve “Modeling/Fashion” as the canonical label, and leave competition covers separate from category artwork.
