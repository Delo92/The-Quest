The approved category visuals are the reference artwork supplied for Music, Modeling/Fashion, Bodybuilding, Fitness, Dance, Comedy, Acting, Brand & Business, Sports, and Reality. Existing Firestore category records must be synchronized to those local web assets; Reality must never use the Starr Struck competition poster.

**Why:** Firebase Storage artwork URLs were broken in production and generic substitutes did not match the category descriptions or the approved screenshots.

**How to apply:** When changing category artwork, keep the assets in the web bundle, update existing records as well as new seeds, preserve “Modeling/Fashion” as the canonical label, and leave competition covers separate from category artwork.
