---
name: Admin profile media
description: Rules for admin-managed photos and talent videos
---

Admin-managed profile photos may be added without a competition and are stored against the talent profile. Admin-managed videos must select a competition the user belongs to before a Vimeo upload ticket can be created.

**Why:** Photos are part of the reusable talent profile, while videos are routed into competition-specific Vimeo folders and backup destinations.

**How to apply:** Preserve the optional competition behavior for photos and require a valid user competition for video upload or routing changes.
